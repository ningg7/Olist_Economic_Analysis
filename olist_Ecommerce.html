Olist 巴西电商平台数据分析¶

项目背景¶

本项目基于公开 Olist 巴西电商数据集，模拟完整业务分析流程： 原始 CSV 数据导入 SQLite 数据库 → 数据探查与异常清洗 → SQL 计算核心业务指标 → 用户 RFM 分层分析 → 输出业务运营建议。

数据集介绍¶

数据集包含订单、客户、订单明细、支付、评价、商品、卖家等多张关联表。

表名 内容说明
orders 订单主表：订单状态、下单时间、客户ID
order_items 订单明细表：商品、卖家、单订单金额
customers 客户表，customer_unique_id 代表真实用户，用于去重统计用户
order_payments 订单支付方式信息
order_reviews 用户评价信息，用于差评分析
products 商品基础信息、商品类目
sellers 卖家信息

核心指标统计口径¶

  1. GMV：有效订单金额总和；剔除 cancelled、unavailable 订单；统计依据为订单下单时间。
  2. 月度 GMV 环比 MOM：使用窗口函数 LAG 获取上月 GMV，计算公式为 (本月GMV - 上月GMV) / 上月GMV。
  3. 复购率：使用 customer_unique_id 识别真实用户；复购用户定义为历史下单次数 ≥ 2 的用户；复购率 = 复购用户数 / 全部有效用户；本项目采用全周期复购口径。
  4. 差评率：评分 ≤ 2 定义为差评；差评率 = 差评订单数 / 总评价订单数；统计时过滤类目为空数据。
  5. RFM 定义
  • R（Recency）：距离用户最近一次下单的天数，天数越大用户越沉睡，打分反向处理。
  • F（Frequency）：用户历史下单总次数。
  • M（Monetary）：用户累计消费金额。
  • 分箱方式：采用 qcut 五分位等频分箱，拼接 R-F-M 分数映射 8 类用户群体。

数据过滤规则¶

  1. 取消订单、不可用订单不参与 GMV、复购计算。
  2. 类目为空的数据，在差评统计时过滤。
  3. RFM 计算只保留有有效下单行为的用户。

sql_gmv_monthly="""
with u as(
SELECT strftime ('%Y-%m',a.order_purchase_timestamp)as month ,sum(b.price) as gmv 
FROM orders a
join order_items b
on b.order_id=a.order_id
where a.order_status not in('canceled','unavailable')

LAG(gmv) OVER(ORDER BY month) pre_gmv,
round(((gmv-LAG(gmv) OVER(ORDER BY month))/LAG(gmv) OVER(ORDER BY month)*100),2) as mom_pct

sql_repurchase="""
WITH t AS(
SELECT customer_unique_id,count(order_id) AS re_cnt
FROM orders a
JOIN customers d
ON d.customer_id=a.customer_id
WHERE a.order_status NOT IN('canceled','unavailable')
GROUP BY d.customer_unique_id
)
SELECT

FROM t;

五、RFM客户价值分层分析¶

先通过SQL提取每位客户的消费时间、订单次数、消费总额，再用Pandas计算最近消费间隔Recency，最后对R/F/M指标打分分层，识别高价值、流失、新客等客户群体。

In [17]:
sql_rfm = """
SELECT 
    c.customer_unique_id,
    MAX(o.order_purchase_timestamp) AS last_purchase,
    COUNT(o.order_id) AS frequency,
    SUM(oi.price) AS monetary
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
JOIN order_items oi ON o.order_id = oi.order_id
WHERE o.order_status NOT IN ('canceled', 'unavailable')
GROUP BY c.customer_unique_id
"""

df_rfm = pd.read_sql(sql_rfm, conn)
df_rfm['last_purchase'] = pd.to_datetime(df_rfm['last_purchase'])

# 计算 R 值（最近一次消费距离数据集最后一天的天数）
# 找一个参照日期（比如数据集里最大的时间）
max_date = df_rfm['last_purchase'].max()
df_rfm['recency'] = (max_date - df_rfm['last_purchase']).dt.days
In [19]:
# 分箱打分，注意 R 值越小越好（越近），所以分数要倒过来
df_rfm['R_score'] = pd.qcut(df_rfm['recency'], 5, labels=[5, 4, 3, 2, 1])
df_rfm['F_score'] = pd.qcut(df_rfm['frequency'].rank(method='first'), 5, labels=[1, 2, 3, 4, 5])
df_rfm['M_score'] = pd.qcut(df_rfm['monetary'], 5, labels=[1, 2, 3, 4, 5])

# 把打分拼接起来，比如 "555"
df_rfm['RFM_score'] = df_rfm['R_score'].astype(str) + df_rfm['F_score'].astype(str) + df_rfm['M_score'].astype(str)
# 定义分层规则
def segment_user(row):
    r, f, m = int(row['R_score']), int(row['F_score']), int(row['M_score'])
    if r >= 4 and f >= 4 and m >= 4: return '重要价值客户'
    if r >= 4 and f < 4 and m >= 4: return '重要发展客户'
    if r < 4 and f >= 4 and m >= 4: return '重要保持客户'
    if r < 4 and f < 4 and m >= 4: return '重要挽留客户'
    if r >= 4 and f >= 4 and m < 4: return '一般价值客户'
    if r >= 4 and f < 4 and m < 4: return '一般发展客户'
    if r < 4 and f >= 4 and m < 4: return '一般保持客户'
    return '一般挽留客户'

df_rfm['user_segment'] = df_rfm.apply(segment_user, axis=1)

# 看看每个层级有多少人
segment_counts = df_rfm['user_segment'].value_counts().reset_index()
segment_counts.columns = ['user_segment', 'user_count']
print(segment_counts)
# 1. 算占比
segment_counts['percentage'] = (segment_counts['user_count'] / segment_counts['user_count'].sum()) * 100
segment_counts['percentage'] = segment_counts['percentage'].round(2)

# 2. 打印看看
